判题内核

fork + 降权 nobody + rlimit 资源限制，2s / 256MB 硬性约束，信号量限流防止死循环代码拖垮服务器。

细粒度结果

总体状态 + 逐用例比对 + 实际运行时间与内存峰值，编译错误附完整 g++ 日志，问题一眼定位。

数据持久化

题目 / 用户 / 提交记录全部落 MySQL，预编译 SQL 防注入，密码加盐哈希存储，会话 Cookie 鉴权。

嵌入式编辑器

基于 ace.js 的 C++ 代码编辑器，语法高亮、行号、Tab 缩进，Ctrl+Enter 一键提交，还原 LeetCode 体验。
